# 框架反击与辩论护盾实战指南

## 话语权控制的三层本质

1. **第一层：事实之争（低效区）**
   - 对方：“你总是迟到，没有职业精神。”
   - 错误回应：“我上个月只迟到了两次，而且是因为地铁故障！”（在对方预设的法庭上当被告）
2. **第二层：定义之争（中效区）**
   - 进阶回应：“如果按时坐在工位上打瞌睡叫职业精神，那真正高效解决线上事故的人该叫什么？”
3. **第三层：框架颠覆（必杀区）**
   - 顶级回应：“你今天这么关心我的考勤打卡，是因为手头主导的项目已经没有更有价值的产出可以汇报了吗？”（身份置换 + 焦点转移）

## 5 大策略心法速查表

| 策略名称 | 适用场景 | 核心动作 | 心理效应 |
| :--- | :--- | :--- | :--- |
| **类比反射** | 恶意评判、道德绑架 | 提取评价结构，代入日常生活公认动作 | 让对方体会到同等逻辑的荒谬与冒犯 |
| **借力打力** | 自我炫耀、优越感贬低 | 顺应其自夸的前提，直接滑向低劣物 | 将其引以为傲的资本瞬间贬值 |
| **放大荒谬** | 强词夺理、不合理要求 | 将其要求无限推向极端不合常理边界 | 迫使对方不得不自己承认荒谬性 |
| **身份置换** | 爹味说教、好为人师 | 审视提问者的资质、历史污点与利益相关 | 剥夺其审判官光环 |
| **定义反转** | 标签化贬损（廉价/小气） | 承认标签词，但赋予其是由对方造成的因果链 | 武器反向击穿发难者 |
