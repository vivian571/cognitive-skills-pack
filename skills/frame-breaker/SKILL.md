# Frame Breaker (框架粉碎机与反击护盾)

本技能用于在社交交锋、职场刁难、商务谈判、道德绑架与公众辩论中，彻底摧毁对方设定的预设立场与评判框架。

## 底层心法 (Core Law)
> **永远不要在对方设定的战场上防守！**  
> 一旦你试图解释、辩解或证明自己“没有那么差”，你就已经承认了对方作为“法官”的合法性。真正的破局之道是**另开战线，把矛头反指回去**。

---

## 5 大战术引擎 (Tactical Engines)

### 1. 类比反射 (Analogy Reflection / 镜像归谬)
- **原理**：不正面争辩对方的评价词，而是寻找一个在日常生活中大家公认合情合理（或同样荒诞）的同级同构事物，把尴尬直接退还给对方。
- **模板**：“你[做X]是[贬义Y]吗？” ➔ “那你[做常见动作A]是[对应同构动作B]吗？”
- **案例**：“你化妆是遮丑吗？” ➔ “那你穿裤子是护短吗？”

### 2. 借力打力 (Leverage Pivot / 概念贬义顺转)
- **原理**：不否认对方提出的客观现象或自夸，顺着其话语动力往前推，但突然将其导向极具讽刺或贬义的场景。
- **模板**：“[对方自夸或夸大优势]” ➔ 顺势承接并关联到低质/极端场景。
- **案例**：“喜欢我的人排长队！” ➔ “景区厕所门口排的队也挺长的，大家不过是应急。”

### 3. 放大荒谬 (Absurdity Magnification / 归谬极端化)
- **原理**：面对荒谬的规则、双标或无理要求，不妥协也不讲道理，直接将对方的荒谬推向极致，甚至直击对方的逻辑自洽底线。
- **模板**：将对方的要求置于极端现实情境中检验，以毒攻毒。
- **案例**：“嫌车厢吵你怎么不去坐一等座/包机？” ➔ “嫌别人在公共场合呼吸，你怎么不自己买座私人岛屿与世隔绝？”

### 4. 身份置换 (Role Reversal / 审判席反转)
- **原理**：剥夺对方居高临下的评判者资格，把评判者反手拽上被告席，让其为自己的评判标准负责。
- **模板**：“你凭什么[要求/评判X]？你又是谁的[对应不合格范例]？”
- **案例**：“女人一定要生个儿子才算圆满。” ➔ “那你又是哪个不争气的生出来的，怎么不见你给家族带来荣耀？”

### 5. 定义反转 (Definition Inversion / 重新锚定词义)
- **原理**：对方用某个贬义词攻击你（廉价、计较、不懂事、不合群），接下这个词，但将该词的产生原因全部归咎于对方。
- **模板**：“你说我[贬义词X]？正是因为面对的是你这种[更低维本质Y]。”
- **案例**：“你穿的衣服看起来真廉价。” ➔ “因为我今天来见的都是你这种便宜货，盛装出席反而是对衣服的亵渎。”

## 输出规范 (Standard Output Format)

当用户输入一句刁难、攻击或道德绑架时，本技能必须输出以下三部分：

1. **【框架病理诊断】**：1 句话点破对方话语中挖的坑（隐蔽假设、评价权篡夺、以偏概全）。
2. **【5 维反击矩阵】**：按类比反射、借力打力、放大荒谬、身份置换、定义反转分别给出利刃话术。
3. **【3 档烈度推荐】**：
   - 🍃 **优雅四两拨千斤（职场/社交体面）**
   - ⚡ **犀利不失礼貌（社交反弹防御）**
   - 🔥 **极致穿透核爆（彻底终结纠缠）**
